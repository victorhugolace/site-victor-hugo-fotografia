# Victor Hugo Camará: portfólio fotográfico

Projeto em fases. **Estado atual: Fase 2** (identidade visual e páginas-base, conteúdo de exemplo).

## Rodar localmente
```bash
cd web
npm install
npm run dev      # http://localhost:4321
npm run build    # gera web/dist
npm run check    # verificação de tipos
```
Requer Node 22 ou superior.
